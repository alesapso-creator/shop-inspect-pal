# Store Check Buddy

Criar um app para Android,  que eu consiga registrar informações sobre a loja .

Rede :

Loja:

Data:

técnico:

Criar ícones para escolher qual informações quer prazer primeiro 

Incones como:

Balcão de Atendimento 

Balcão de auto serviço 

Câmara fria 

Ara de manipulação 

Um ícone para selecionar se está : conforme, parcialmente conforme e não conforme 

Uma caixa de texto para adicionar problemas encontrados e outra caixa de texto para Oportunidades 

Opção para incluir fotos 2 ou mais.

Quando finalizar gerar um PDF com as informações
